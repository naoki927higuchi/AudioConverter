# 最新バイナリー

公開用に選定・検証したWindows版です。製品名のリンクから配布ZIPをダウンロードできます。

| 製品 | 最新公開版 | SHA256 |
|---|---|---|
| [AudioConverter（ZIP）](https://github.com/naoki927higuchi/AudioConverter/raw/refs/heads/main/distribution/AudioConverter-2.0.0-x64.zip) | 2.0.0 | [チェックサム](AudioConverter-2.0.0-x64.zip.sha256) |

Windows 11 / Intel・AMD x64用です。.NETは同梱しています。FFmpegは同梱していません。利用者が別途FFmpegを用意し、ffmpeg.exeのあるbinフォルダーをユーザー環境変数PATHに追加して、サインアウト・再ログインしてください。libmp3lameとdynaudnormに対応したビルドが必要です。ZIPを展開してInstall.cmdを実行します。初回の自己署名公開証明書登録には管理者承認が必要です。詳しくは[README.txt](README.txt)を参照してください。
